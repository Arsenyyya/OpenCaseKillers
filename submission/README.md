Основной PDF — **5 страниц**, основной текст и таблицы — **12 pt**; порядок вопросов **1, 2, 3, 4, 6**. Лимит 15 000 проверяется с пробелами и дополнительным запасом на разделители и повторяющиеся колонтитулы. Презентация — **10 слайдов**. Точные счётчики и финансовые расчёты сохраняются в [checks.json](checks.json).

В папке `final/` находятся только пять финальных файлов. В архив `OpenCaseKillers_submission.zip` входят три обязательные части: `Решение.pdf`, `Метрики.md`, `Презентация.pptx`. Площадка чемпионата может вводить дополнительные правила загрузки, которых нет в предоставленном PDF.

Дополнительный [AI Footnotes](optional/AI_Footnotes.md) допустим по странице 3 кейса, но необязателен. Оценка удовлетворённости ИИ оставлена честно как «не выставлена командой». Его можно приложить отдельно после проверки участниками. Этот README, сверка требований, исходники генерации, checks.json, backend и 13-страничный технический отчёт **не входят в конкурсный ответ** и не используются в основном решении или слайдах для обхода ограничения объёма.

## Что изменено по сравнению с техническим отчётом

Теперь есть самостоятельный ответ по всем шести вопросам кейса: архитектура с причинами сервисных границ, tools и доступы, промпт с пояснениями, приёмка, отдельные паспорта метрик с ретроспективой и fallback, доходная финансовая модель с тремя сценариями, макрофакторами и сравнением альтернатив. Финансовые входы являются допущениями; 86 автоматических тестов и синтетический demo не подменяют качество реальной Qwen.

## Пересборка

```sh
make submission
```

Команда устанавливает docs-зависимости и запускает `scripts/build_submission.py`. Нужны Arial, Liberation Sans либо DejaVu Sans. Содержание основного решения находится в `source/solution.json`, сцены презентации — в генераторе; файл метрик редактируется напрямую. Генератор проверяет лимит, порядок вопросов, число страниц/слайдов, UTF-8, переполнение текстовых блоков, поддерживаемые глифы, ссылки и арифметику финансовых сценариев. Исходный PDF компании для сборки не требуется и в репозитории не распространяется.

PDF и PPTX презентации строятся из одних сцен с одинаковыми переносами. Точное расположение текста PPTX может слегка зависеть от шрифтов установленного PowerPoint; PDF зафиксирован и просмотрен. Пагинация DOCX может различаться в редакторах; конкурсный PDF имеет проверенные 5 страниц. Защита участниками, согласование корпоративных входных данных и фактическая отправка на площадку не выполнены автоматически.
